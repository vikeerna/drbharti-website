# Website collaboration

- Work only on this public website. The clinical practice software is a separate project.
- Read `.ai/CURRENT.md` before editing. Use one active editor and task branches; record the handoff.
- Preserve existing URLs, source provenance and unrelated work. Separate baseline imports from improvements.
- Never commit patient logs, identifiable private records, credentials or private marketing reports. Existing publicly served media are not authorisation to add new patient media.
- Use owner-confirmed professional facts. Do not invent outcomes, patient counts, fees, qualifications, attendance, testimonials or facility capabilities.
- Garhwa visits must be confirmed; the usual first/third Sunday pattern is not a guaranteed appointment.
- Keep metadata, visible content and structured data consistent. Contact events must not contain form contents or personal details.
- Test relevant mobile layout, links, JavaScript, schema and contact behaviour. Record actual results and remaining limitations.
- Follow the owner's current task authorisation and any explicit platform approval gate. Never report a merge or deployment without evidence.
